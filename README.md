## Projetos em destaque

### Agente de IA com base de conhecimento empresarial (RAG)

Agente que consulta uma base corporativa antes de responder, utilizando RAG, embeddings e busca vetorial. O fluxo em n8n inclui ingestão de documentos, recuperação semântica, fallback e encaminhamento para atendimento humano.

**Tecnologias:** n8n, RAG, Supabase, PostgreSQL, embeddings e LLMs.

[Ver projeto](https://github.com/matheusmodesto-prog/agente-rag-base-conhecimento)

### Automação inteligente de atendimento com IA

Automação conversacional para processamento de mensagens, gestão de contexto, identificação de intenção, qualificação de contatos e escalonamento para atendimento humano.

**Tecnologias:** n8n, LLMs, APIs, webhooks e Google Sheets.

[Ver projeto](https://github.com/matheusmodesto-prog/automacao-atendimento-ia-n8n)

### Automação de follow-up comercial com IA

Fluxo que identifica contatos elegíveis, recupera o contexto, gera mensagens personalizadas com LLM e realiza o envio via API do WhatsApp.

**Tecnologias:** Make, LLMs, APIs, Google Sheets e WhatsApp.
